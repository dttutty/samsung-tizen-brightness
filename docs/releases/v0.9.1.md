Windows 11 x64; .NET 10.0.12 is bundled. No separate runtime installation is needed.

## 更新 / Changes

- 通过 IP Remote 直接读写硬件背光，不需要电视端 Tizen 桥接器、开发者模式或开发证书。
- 移除自动开关机、Wake-on-LAN 与倒计时；不会改变显示器自身的无信号待机行为。
- 提供中／英／韩／西班牙语界面、README 和对应界面截图。
- 保留 Windows 深浅色模式按钮、登录自启动与加密授权保存；普通点击不会重复申请权限。

Direct hardware-backlight control via IP Remote, with no TV companion app or Developer Mode. Automatic power control, Wake-on-LAN and countdowns are removed. Includes four-language UI and documentation, Windows color-mode switching, optional login startup and locally encrypted authorization.

## 设置 / Setup

在电视上开启 / Enable on the TV:

**Settings → All Settings → Connection → Network → Expert Settings → IP Remote → Enable**

然后右键托盘图标选择 **授权 IP Remote… / Authorize IP Remote…**，在电视上选择一次 **Allow**。
Keep the TV on while pairing. Older models may place Network under General.
